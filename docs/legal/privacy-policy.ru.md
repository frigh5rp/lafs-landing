## 1. Какие данные мы обрабатываем

| Категория | Примеры | Зачем |
|-----------|---------|--------|
| Данные аккаунта / VK ID | идентификатор VK, токены сессии, имя и аватар (если переданы при входе) | регистрация, вход, защита аккаунта |
| Профиль | имя, фото, пол, возрастная категория, пол/возраст/радиус поиска | показ профиля, подбор совпадений |
| Геолокация | координаты при включённом поиске | поиск собеседников рядом |
| Технические | идентификаторы сессии, IP (на стороне сервера/логов), тип клиента, время событий | работоспособность, безопасность, диагностика |
| События созвонов | факт входящего/принятого/завершённого созвона, служебные идентификаторы сессии | соединение пользователей, антифрод |
| Платежи / Premium (если используются) | сведения о статусе подписки/пакетов, без хранения полных данных карты Оператором (если оплата через сторонний платёжный сервис) | предоставление платных функций |

**Важно про голос:** в текущей версии LAFS голосовой созвон нужен для общения в реальном времени. Оператор **не заявляет** обработку голоса как биометрических персональных данных для идентификации личности и **не обещает** централизованное хранение аудиозаписей разговоров.

**VK ID:** при входе часть данных обрабатывается ООО «ВК» / сервисами VK на условиях VK. Оператор получает от VK только сведения, необходимые для работы Аккаунта LAFS.

Мы **не просим** паспортные данные при обычной регистрации.

## 2. Цели и правовые основания

Обработка осуществляется для:

- предоставления функций Сервиса (регистрация, профиль, матчинг, созвон);  
- обеспечения безопасности и предотвращения злоупотреблений;  
- исполнения требований закона;  
- связи с Пользователем по вопросам Сервиса;  
- предоставления платных функций (если вы их приобретаете).

Основания (в зависимости от операции): исполнение договора с Пользователем (Соглашение), согласие Пользователя (где требуется), законные интересы Оператора при условии соблюдения прав субъекта ПДн, исполнение обязанностей, установленных законом.

## 3. Геолокация

3.1. Геолокация запрашивается через системные разрешения устройства.  
3.2. При выключенном поиске актуальные координаты для матчинга не используются.  
3.3. Точный «постоянный трекинг» вне сценария поиска не является целью Сервиса.

## 4. Кому могут передаваться данные

4.1. Обработчикам по поручению Оператора (хостинг, инфраструктура, необходимые технические подрядчики) — в объёме, нужном для работы Сервиса.  
4.2. Провайдеру VK ID — в рамках авторизации.  
4.3. Государственным органам — в случаях и порядке, предусмотренных законом РФ.  
4.4. Собеседнику в рамках Сервиса — элементы профиля, необходимые для входящего созвона/знакомства (например, имя и фото).

Трансграничная передача — только при соблюдении требований 152‑ФЗ.

## 5. Сроки хранения

- данные аккаунта и профиля — пока Аккаунт активен и в течение разумного срока после удаления (для завершения обязательств, безопасности, споров), если более длительный срок не требуется законом;  
- геолокация для матчинга — пока нужен активный поиск / в оперативных целях;  
- технические логи — ограниченный срок, достаточный для безопасности и диагностики;  
- сведения о созвонах (метаданные) — ограниченный срок для работы сервиса и антифрода.
