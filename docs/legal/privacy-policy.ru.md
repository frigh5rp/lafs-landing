## 1. Какие данные мы обрабатываем

| Категория | Примеры | Зачем |

| Данные аккаунта / VK ID | идентификатор VK, токены сессии, имя и аватар (если переданы при входе) | регистрация, вход, защита аккаунта |

| Проверка личности | фото профиля и фото с жестом (челлендж), статус проверки, служебные оценки автопроверки | безопасность, допуск к поиску, модерация |
| Технические | идентификаторы сессии, IP (на стороне сервера/логов), тип клиента, push-токен устройства, время событий | работоспособность, уведомления, безопасность, диагностика |

| Платежи / Premium | сведения о статусе подписки/пакетов «Стрела Купидона» и Premium; идентификаторы платежей у платёжного провайдера (ЮKassa и аналоги); полные данные карты Оператор не хранит | предоставление платных функций |

**Важно про голос и видео:** голосовой и (при согласии сторон) видеозвонок нужны для общения в реальном времени. Медиа передаётся между устройствами (WebRTC); Оператор **не заявляет** обработку голоса/изображения лица как биометрических персональных данных для идентификации личности в смысле отдельной биометрической системы и **не обещает** централизованное хранение аудио- или видеозаписей разговоров.

**Проверка по фото/жесту:** это мера безопасности Сервиса (подтверждение, что за профилем человек, а не чужое фото). Фото для проверки обрабатываются на сервере и могут просматриваться уполномоченными сотрудниками модерации. Это **не** сдача биометрии в государственную систему. Отказ от проверки может ограничить доступ к поиску.

**VK ID:** при входе часть данных обрабатывается ООО «ВК» / сервисами VK на условиях VK. Оператор получает от VK только сведения, необходимые для работы Аккаунта LAFS.

Мы **не просим** паспортные данные при обычной регистрации.

Основания (в зависимости от операции): исполнение договора с Пользователем (Соглашение), согласие Пользователя (где требуется, в т.ч. на обработку ПДн и на отдельные разрешения устройства), законные интересы Оператора при условии соблюдения прав субъекта ПДн, исполнение обязанностей, установленных законом.

## 3. Геолокация

3.1. Геолокация запрашивается через системные разрешения устройства **только при использовании приложения** (без фонового трекинга вне активного сценария поиска).  
3.2. При выключенном поиске координаты **удаляются с сервера** и для матчинга не используются.  
3.3. Точный «постоянный трекинг» вне сценария поиска не является целью Сервиса. Собеседнику **не передаются** ваши точные координаты — подбор выполняется на сервере; в интерфейсе может отображаться лишь факт «рядом» / результат матча.  
3.4. Устаревшие координаты (например, без обновления дольше ~30 минут) автоматически очищаются.  
3.5. Уполномоченный персонал Оператора (администрирование безопасности) может видеть **приблизительное** положение пользователей в активном поиске (с округлением, без необходимости точного адреса) — исключительно для поддержки и антифрода.

## 4. Кому могут передаваться данные

4.1. Обработчикам по поручению Оператора (хостинг, инфраструктура, push-провайдер, STUN/TURN и иные необходимые технические подрядчики) — в объёме, нужном для работы Сервиса.  
4.2. Провайдеру VK ID — в рамках авторизации.  
4.3. Платёжному провайдеру (например, ЮKassa) — при оплате Premium / пакетов, в объёме, необходимом для платежа.  
4.4. Государственным органам — в случаях и порядке, предусмотренных законом РФ.  
4.5. Собеседнику в рамках Сервиса — элементы профиля, необходимые для входящего созвона/знакомства (например, имя и фото), **без** точных координат.

Трансграничная передача — только при соблюдении требований 152‑ФЗ.

## 5. Сроки хранения

- данные аккаунта и профиля — пока Аккаунт активен и в течение разумного срока после удаления (для завершения обязательств, безопасности, споров), если более длительный срок не требуется законом;  
- геолокация для матчинга — только на время активного поиска; при остановке поиска и по истечении срока актуальности координаты удаляются;  
- материалы проверки личности (фото жеста / связанные статусы) — пока нужны для допуска к поиску, модерации и споров, затем удаляются или обезличиваются в разумный срок;  
- жалобы и логи модерации — ограниченный срок, достаточный для безопасности и разбора обращений;  
- технические логи и push-токены — ограниченный срок / до удаления аккаунта или отзыва разрешения;  
- сведения о созвонах (метаданные) — ограниченный срок для работы сервиса и антифрода;  
- сведения о платежах — в сроки, необходимые для бухгалтерии, претензий и требований закона / правил платёжного провайдера.
