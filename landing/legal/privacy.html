Политика конфиденциальности сервиса LAFS

Политика является неотъемлемой частью Пользовательского соглашения.

1. Какие данные мы обрабатываем

Важно про голос: в текущей версии LAFS голосовой созвон нужен для общения в реальном времени. Оператор не заявляет обработку голоса как биометрических персональных данных для идентификации личности и не обещает централизованное хранение аудиозаписей разговоров. VK ID: при входе часть данных обрабатывается ООО «ВК» / сервисами VK на условиях VK. Оператор получает от VK только сведения, необходимые для работы Аккаунта LAFS. Мы не просим паспортные данные при обычной регистрации.

2. Цели и правовые основания

Обработка осуществляется для: - предоставления функций Сервиса (регистрация, профиль, матчинг, созвон); - обеспечения безопасности и предотвращения злоупотреблений; - исполнения требований закона; - связи с Пользователем по вопросам Сервиса; - предоставления платных функций (если вы их приобретаете). Основания (в зависимости от операции): исполнение договора с Пользователем (Соглашение), согласие Пользователя (где требуется), законные интересы Оператора при условии соблюдения прав субъекта ПДн, исполнение обязанностей, установленных законом.

3. Геолокация

3.1. Геолокация запрашивается через системные разрешения устройства. 3.2. При выключенном поиске актуальные координаты для матчинга не используются. 3.3. Точный «постоянный трекинг» вне сценария поиска не является целью Сервиса.

4. Кому могут передаваться данные

4.1. Обработчикам по поручению Оператора (хостинг, инфраструктура, необходимые технические подрядчики) — в объёме, нужном для работы Сервиса. 4.2. Провайдеру VK ID — в рамках авторизации. 4.3. Государственным органам — в случаях и порядке, предусмотренных законом РФ. 4.4. Собеседнику в рамках Сервиса — элементы профиля, необходимые для входящего созвона/знакомства (например, имя и фото). Трансграничная передача — только при соблюдении требований 152‑ФЗ.

5. Сроки хранения

- данные аккаунта и профиля — пока Аккаунт активен и в течение разумного срока после удаления (для завершения обязательств, безопасности, споров), если более длительный срок не требуется законом; - геолокация для матчинга — пока нужен активный поиск / в оперативных целях; - технические логи — ограниченный срок, достаточный для безопасности и диагностики; - сведения о созвонах (метаданные) — ограниченный срок для работы сервиса и антифрода.

Вы вправе: - получать сведения об обработке ваших ПДн; - требовать уточнения, блокирования или удаления — в случаях, предусмотренных 152‑ФЗ; - отозвать согласие (если обработка основана на согласии), понимая, что это может сделать невозможным использование части функций; - обратиться с жалобой в Роскомнадзор и/или в суд. Запросы направляйте на lafs.tech@mail.ru. Для защиты Аккаунта Оператор может запросить подтверждение, что запрос исходит от вас.

7. Удаление аккаунта

Удаление доступно через настройки приложения и/или по обращению на lafs.tech@mail.ru. После удаления основные данные профиля перестают использоваться для Сервиса; отдельные сведения могут храниться дольше, если это необходимо по закону или для защиты прав Оператора.

8. Безопасность

Оператор применяет организационные и технические меры защиты (разграничение доступа, защита канала связи где применимо, хранение секретов доступа в защищённом виде и т.п.). Абсолютную безопасность передачи данных в сети Интернет гарантировать невозможно.
